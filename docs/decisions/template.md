# ADR-NNNN: Tytuł decyzji

- Status: Proponowana
- Data: RRRR-MM-DD
- Autor / osoby uzgadniające: do uzupełnienia
- Powiązania: zadanie, PR lub wcześniejszy ADR

## Kontekst

Jaki problem rozwiązujemy? Jakie wymagania i ograniczenia mają znaczenie?

## Rozważane opcje

Jakie rozwiązania rozważamy, łącznie z pozostawieniem obecnego stanu? Jakie są ich zalety i koszty?

## Decyzja

Co wybieramy i dlaczego? Co pozostaje poza zakresem?

## Konsekwencje

Korzyści, koszty, ograniczenia, ryzyka i wpływ na istniejący kod lub rozgrywkę.

## Weryfikacja

Jak sprawdzimy, że rozwiązanie spełnia wymagania? Jakie warunki uzasadnią ponowne rozważenie decyzji?
